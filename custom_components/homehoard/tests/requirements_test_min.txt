# this leg runs on Python 3.12. CI asserts the installed HA equals hacs.json.

# only when hacs.json's minimum moves, to the harness release for that HA.
#
# Same rule as requirements_test.txt: venv only, never the backend interpreter.

#   lingering-thread check reports as a test error.
